## 统一响应

异步入口 `/api/analyses` 的创建、状态和取消返回 `TaskStatusResponse`；结果返回 `TaskResultResponse`。两者均带 `schema_version: "1.0"` 和 `responseType`，任务字段使用 camelCase 传输名（`taskId`、`dataSource`、`networkRequests` 等）。旧 `/api/v1/analysis` 地理分析入口继续返回 `AnalysisResponse`，共享 `Data`、`Rules`、坐标和单位定义。

`status` 表示异步任务传输状态：`running`、`cancelling`、`completed`、`cancelled`、`failed`。`businessStatus` 表示业务结果：`complete`、`partial`、`failed`、`empty`。任务完成不代表业务完整：当前设施和报告尚未接入，因此正常等时圈结果映射为 `completed + partial`；证据不足映射为 `completed + failed`；执行异常映射为 `failed + failed`；取消时为 `cancelled + null`。`empty` 仅用于模块已执行且结果集合确为空，不能把未执行模块当作空结果。

## 设施分类与数据语义

设施和分类结果同时提供 `major_category`、`minor_category`，并保留 `category` 作为二级字段的兼容名称。一级分类固定为：`shopping`（购物）、`medical`（医疗服务）、`education`（教育）；二级分类可用 `market`、`supermarket`、`pharmacy`、`hospital_pharmacy`、`school`。幼儿园不归入教育二级分类。

首版所有经纬度均为 BD09LL，坐标顺序为 `[longitude, latitude]`。距离单位为米（`m`），时间为秒（`s`），面积为平方米（`m2`）。缺失值使用 `null` 表示未查询、不可判定或模块未执行；空数组 `[]` 表示模块已执行且确实没有结果；空几何使用 `MultiPolygon` 且 `coordinates: []`。这三种情况不能互相替代。

## 生成与验证

在 `backend` 目录执行 `\.venv\Scripts\python.exe -m tools.export_contract`，会重新生成：

- `docs/openapi.json`（异步接口引用 `TaskStatusResponse` / `TaskResultResponse`）；
- `docs/analysis-response.schema.json`；
- `mocks/complete.json`、`partial.json`、`failed.json`、`empty.json`；
- `life-circle-demo/src/api-contract.ts`（含任务模型和设施层级字段）。

契约测试覆盖四种 Mock、任务模型校验、OpenAPI 响应引用、业务状态映射和分类层级字段。当前服务仍是单进程内存任务，真实设施统计和多用户部署不在 N05 范围内。
