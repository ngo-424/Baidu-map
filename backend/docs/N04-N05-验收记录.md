先按 backend/README 安装锁定依赖和本地算法包；以下从 backend 运行。临时目录仅供pytest，不能放个人文件。

```powershell
.\.venv\Scripts\python.exe -m tools.export_contract
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp=logs/n04-pytest-recheck
.\.venv\Scripts\python.exe -m tools.verify_analysis_http
.\.venv\Scripts\python.exe -m pip check
```


## 本次发现与修复

1. 算法几何含 `coordinateSystem`，严格HTTP模型最初拒绝；增加显式输入别名，规范化输出 `coordinate_system`，原件保留在algorithm中，真实HTTP验证通过。
2. 本机旧pytest临时目录权限不足；改用backend/logs下独立目录，不改用户临时目录权限。
3. 原N02 CLI缺密钥测试在Windows子进程中丢失空环境变量，导致回退本地.env并意外发出一次地点检索（HTTP200、百度status0、结果0条）。没有打印密钥；该请求不能证明步行算法已实测。改用可继承的空白字符串覆盖，Settings会去空白后判缺密钥；修正后全部测试通过，不再触发此请求。
4. 保留现有Starlette/HTTPX测试客户端两条弃用警告；本次未为消除警告升级依赖。
