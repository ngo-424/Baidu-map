## 合成边界样例与三态

可机器读取的样例：`backend/tests/fixtures/n04-boundaries.json`，执行测试：`backend/tests/test_analysis.py`。

| 样例 | 预期 |
| --- | --- |
| 899.9 / 900 / 900.1 秒 | true / true / false |
| 时长 null、负数、上游未知 | null；不等于不可达 |
| 明确步行距离且含等号，999.9 / 1000 / 1000.1m，容差0 | true / true / false（通用边界样例） |
| 明确不含等号，恰好1000m | false |
| 类型未确认、等号未确认、容差未确认、距离缺失、度量不匹配 | null |
| 已确认容差100m：899 / 900 / 1000 / 1100 / 1101m | true / null / true / null / false |
| 同一起点步行距离950m、用时950s | 距离成立、15分钟不可达；规则互不替代 |
| 类别查询不完整、或任何距离未知且无已知符合设施 | unknown，不得判 blind |
| 完整查询且所有候选均不符合（包含空数组） | 仅评估范围及类别口径已明确时 blind |

合成场景 `plane`、`local_failure`、`global_failure` 分别覆盖正常时间场、局部缺测、全体外部采样缺测。未知区域保留在响应；有效空几何用空 MultiPolygon，证据不足用 null，不相互替换。算法已有孔洞、窄通道、河流/围墙绕行与恰好边界退化几何测试，回归结果见验收记录。

## 调用方法

先按 backend/README 安装依赖（后端环境需要安装本地算法包）。在 backend 目录启动：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

第二个终端发出无密钥合成请求：

```powershell
$payload = @{ origin = @{ lng = 116.4; lat = 39.9 }; coordinate_system = 'bd09ll'; scenario = 'plane'; budget = 400 } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/v1/analysis/synthetic -ContentType application/json -Body $payload
```

Python直接调用见算法 README：`asyncio.run(compute_isochrone(IsochroneRequest(...), AnalyticProvider(...)))`。FastAPI 使用线程池运行合成计算，避免几何计算阻塞事件循环。该联调接口无任务持久化/取消/服务级配额治理，不作为生产批量分析接口；客户端取消请求不等于服务器计算取消。

真实适配器后续应通过 `async with BaiduProvider(ak=settings.baidu_map_ak.get_secret_value())` 显式传入服务端配置，并在 IsochroneRequest 中设置已核实 QPS；不得以空参环境回退代替配置传递。正式接入还需验证步行权限、道路端点和配额。本次仅验证算法与 FastAPI 合成链路，没有执行真实百度等时圈，也未把 N02 地点检索成功当作步行权限证据。
