# 国定一社区端点核验修复报告

> 后续进展：用户要求继续后已完成真实取消及 200 次分析，累计 210 次。端点解析在线有效；另发现并修复严格 QPS 等待问题，见《国定一社区_首轮真实测试续测报告.md》。下文保留端点修复时的历史记录。

## 1. 结论

**问题位于百度步行适配器的端点坐标解析，已修复并通过真实样本离线回放。** 百度实际返回的分段经纬度是数值字符串，原实现只接受 Python 的 `int` / `float`，因此将存在的端点误判为缺失。

本次新增 1 次真实诊断请求，取得字段类型证据；修复后对同一份脱敏样本回放，`endpoint_verified` 从 false 变为 true。起点偏移 **0.244 米**、终点偏移 **37.087 米**，都小于原有 50 米门槛。完整算法和后端测试 **189 项通过**。

累计真实调用 **9/220 次**。未清空账本、未解除后续分析的停止状态，也未创建取消任务或 200 次完整分析。端点解析修复不等同于社区完整闭环已经验收。

## 2. 根因与证据

### 实际返回与原实现不兼容

北京时间 **2026-09-13 14:30:00**，复查固定中心至东 200 米的位置：

- 请求起点：BD09LL `121.513926, 31.313077`。
- 请求终点：BD09LL `121.516031, 31.313077`。
- HTTP 200，百度 `status=0`，耗时 367 秒，一条路线、四个分段。
- 第一段起点与末段终点均存在，经纬度字段类型全部为字符串。

第一段起点的脱敏结构示例：

```json
{
  "start_location": {
    "lng": "121.51392519758",
    "lat": "31.313079085826"
  }
}
```

原 `life-circle-algorithm/src/life_circle/providers.py` 的 `BaiduProvider._endpoint` 使用 `type(v) in (int, float)` 判断字段，字符串未通过即返回 None。结果是路线耗时仍然有效，但起终点均为 None，`endpoint_verified=false`，真实测试门槛随之阻止后续阶段。

[百度步行接口文档](https://lbs.baidu.com/docs/webapi?title=directionlite/guide/webservice-lwrouteplanapi/walk) 列出了 `steps_info` 和分段起终点字段。本次修复以实际响应的类型证据为依据，没有把字段的语义说明当作 JSON 数字类型保证。

### 原测试和诊断记录的缺口

已有契约测试中的端点都使用 JSON 数字，没有覆盖真实服务返回的数值字符串。首轮账本只保存解析后的坐标，没有保存原字段类型，导致最初只能判定“无法核验”，不能进一步定位原因。

本次诊断仅记录白名单字段的类型、列表长度和合法坐标值，排除 AK、完整 URL、路线说明与任意字符串。对该新增真实样本，已确认是解析类型不兼容；首轮另外七个位置没有完整类型证据，不能逐条声称其原响应已重新验证。

## 3. 修复内容

| 文件 | 改动 |
| --- | --- |
| `life-circle-algorithm/src/life_circle/providers.py` | 数字与合法数值字符串统一转换为有限浮点数，再校验经纬度范围；保留原始坐标精度用于偏移计算 |
| `life-circle-algorithm/tests/test_baidu.py` | 增加真实样本回归、字符串端点偏移、多路线选择、混合类型、畸形字段和超大整数测试 |
| `life-circle-algorithm/tests/fixtures/guodingyi_endpoint_strings.json` | 由本次真实诊断白名单证据构造的最小夹具，仅保留首末段端点和耗时，不含中间分段及路线说明 |
| `backend/tools/live_smoke.py` | 增加有界字段结构记录和显式单请求诊断入口，复用原账本、额度和 QPS；停止状态保持不变 |
| `backend/tests/test_live_smoke.py` | 覆盖诊断只执行一次、重启不能重复、阶段限制、鉴权/配额停止不可绕过及日志脱敏 |

解析接受普通十进制数值字符串以及有限的科学计数法，拒绝布尔值、空串、NaN、Infinity、溢出数、越界经纬度、对象/数组及不合法字符。字符串长度限制为 64，超大整数转换失败被安全处理，不再向上传播 `OverflowError`。

原有 **50 米偏移阈值、多路线选择、缺失端点的未核验状态**均保留。没有使用顶层起终点回显或请求坐标冒充实际端点，没有改动采样评分、算法预算、前后端业务接口或依赖版本。
