## 固定方案

本轮仅实施短时稳定性与独立验证点比较，不评价真实面积 IoU、边界 P95 或拓扑准确率。

公共参数：900 秒、QPS 上限 3、真实请求串行、每次超时 8 秒、最多两次尝试、每阶段截止 600 秒。执行顺序由固定种子预先确定为 adaptive → uniform → radial。

稳定性必须完成 256 个观测，有效且端点核验通过比例至少 95%，临时网络错误及超时尝试比例不超过 1%；无百度限流或鉴权/配额错误，滚动 1 秒最多 3 次、在途最多 1 次。未通过则不进入独立验证。独立有效参考少于 128 个则不开始算法比较。

全部阶段共享生产 RateGate，审计层不补等待。任何本地超频、百度限流、权限、配额或参数错误立即阻止后续发送。启动标记和预算持久化，不允许自动重跑。

### 本地记录异常与后续修复

1. 自适应统计有 `endpoint_offset=9`、`provider_error=1`。账本事件 **761** 只有预算预留和旧的 dispatched 标记，没有 `dispatchPerf`、`responsePerf`、HTTP 状态。因此保守计入 400 次额度，但确认发送只有 399 次。不能把标记字符串当作发送证据。
2. 均匀统计有 `endpoint_offset=14`、`provider_error=1`，但 400 次均有交接和 HTTP/百度成功响应。该 Provider 异常不能据此扣减真实发送数，也不能算作百度业务失败。原工具没有保留本地异常的结构化细分，无法精确归因到某条响应。
3. 原实验工具的账本原子写入异常可能被 Scheduler 归类为普通 provider_error，而后续采样继续。注入 PermissionError 的离线测试复现该缺口。Windows 文件读取与原子替换的共享方式冲突是可能触发路径，但历史异常没有原始异常证据，不能认定已完成具体因果归因。
4. 已在真实运行结束后修复 `ExperimentLedger.save`：记录失败后将全局状态置为 `ledger_write_failed` 并阻止后续发送；保留已预留额度。另增 `reserved_attempts / actual_calls / unconfirmed_reservations`，分别记录预算、确认发送和未确认预留。
5. 新保护仅完成离线回归，未重新请求百度验证，也未重跑三算法。运行时源码完整保存在 `runtime-source/live_comparison.py`，与 config.json 的启动哈希一致；当前工具代码包含后续修复，两者明确区分。

原 `metrics.json`/`result.json` 中的 `actual_calls` 实际取自预算计数，存在上述命名问题，原文件保留用于审计，**当前成本结论以 `audited-metrics.json`、`audited-metrics.csv`、`audit-summary.json` 为准**。审计脚本 `audit_results.py` 不联网，不改写原账本、原结果或几何，也不重新计算采样。点分类指标前后相同。

### 独立验证与点评价口径

验证点 SHA-256：`85b86b9bbda3b7418f6d26556af4cfc853c13ca70b94f04a68ca1ff440b51bec`。

验证点在发送前写入 `protocol.json`，每个 200×200 米格内取一个固定随机点并保留格号。点集代表指定正方形内的空间分层抽样，未按道路入口人工挑选；落在建筑、围墙或其他难以定位步行端点的位置可能因偏移而失效。无效参考造成的覆盖偏差须与误差一起阅读。

算法只收到原点、参数和无缓存的百度 Provider，不读取验证标签。三种方法各用独立 Scheduler 缓存，共享的仅是请求限流器与总账。评价前将三算法采样目的坐标取并集，与验证坐标按六位小数精确比对，命中点从共同评价集合排除，不补采。

- 参考标签：有效且端点核验通过的路线耗时 ≤900 秒为可达，>900 秒为不可达。失败、无结果、未核验或偏移超限的参考不参与分类分母，单独统计。
- 算法预测：`geometry=null` 或落入未知面优先判为未知；否则用可达几何的 `covers` 判定，包含边界。有效空几何不是全部未知。
- 误纳率：预测可达但参考不可达的点数 / 预测可达点数。
- 漏纳率：参考可达但未预测为可达的点数 / 参考可达点数，包含算法未知造成的漏纳。
- 未知点比例：算法未知点数 / 有效且未重合的共同参考点数。分母为零时输出 null。
- 分量、孔洞和未知面积比例仅描述算法输出，不构成拓扑准确率。没有参考边界，因此不计算真实面积 IoU 和边界 P95。

固定先后顺序会带来时间漂移；本轮是一次探索性比较，不做显著性检验或普遍优劣排名。
